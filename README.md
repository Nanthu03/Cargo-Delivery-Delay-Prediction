# Cargo Delivery Delay Prediction

## Project Overview

This project analyzes delivery logistics data and predicts whether a delivery will be delayed using Machine Learning techniques.

## Objectives

* Analyze factors affecting delivery delays.
* Explore the impact of weather conditions on delivery performance.
* Build a Machine Learning model to predict delivery delays.
* Evaluate model performance using suitable metrics.

## Technologies Used

* Python
* Pandas and NumPy
* Matplotlib and Seaborn
* Scikit-learn
* Imbalanced-learn (SMOTE)
* Logistic Regression

## Dataset Features

* Delivery Partner
* Vehicle Type
* Weather Condition
* Distance (km)
* Package Weight (kg)
* Delivery Cost
* Delivery Rating
* Delay Status

## Methodology

1. Data loading and preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature scaling using StandardScaler
4. Handling class imbalance using SMOTE
5. Training a Logistic Regression model
6. Evaluating model performance

## Key Findings

Weather conditions showed a statistically significant relationship with delivery delays in the analyzed dataset.

## Project Outcome

The project demonstrates how Data Analytics and Machine Learning can help analyze delivery performance and predict potential delays.
